# UO Squad Editor

Unofficial fan tool for editing Unicorn Overlord mission squads / tactics presets and exporting a Ryujinx ExeFS mod.

Not affiliated with Atlus, Sega, Vanillaware, or Nintendo. You need your own copy of the game to use mods in an emulator. This repo does not include ROMs, keys, or firmware.

## Quick start

```powershell
cd Tools\mission_editor
npm install
npm run dev
```

Open the localhost URL Vite prints. Export writes a mod under `Mods/` for Ryujinx (`010069401adb8000`).
